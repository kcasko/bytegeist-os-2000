# ByteGeist OS 2000

Source: Keith's approved AWS Challenge Strategy plan, October 28, 2026; implementation requested October 29.

A Windows 98/2000-inspired technical portfolio, with original ByteGeist identity: navy wallpaper, blue title bars, gray beveled controls, compact software layouts. React + TypeScript + Vite, custom CSS, reducer-based window management. No backend needed.

Sprint 0 delivers desktop launchers, Start navigation, taskbar, overlapping movable windows, minimize/restore/maximize/close, keyboard alternatives, and small-screen access. Welcome, Projects, About, Skills, and a clearly labeled ByteWire preview establish application boundaries. Portfolio data is sourced from the existing local portfolio and user-provided background, without inventing credentials.

Later: ByteWire simulated P2P, explicit opt-in fictional malware scenario, separate deterministic incident reducer, prevention and recovery outcomes, persistent Exit Simulation and reset. No actual downloads, executable execution, browser popups, credentials, or system access.

casko.dev and bytespace.casko.dev remain untouched. AWS Amplify is a later release task requiring confirmation before public deployment. The referenced plan lists November 6 as the challenge deadline; official eligibility, rubric, and deadline must be reverified before submission.
