# Sprint 0 Implementation Plan

**Goal:** A working original retro desktop in a separate local Git repository.

**Architecture:** A pure window reducer owns open order, active window, position, minimized and maximized state. Desktop components dispatch actions. Typed registry/content feed app views; future incident state stays separate.

**Tech stack:** React, TypeScript, Vite, CSS variables and CSS Modules, Vitest, Testing Library, Playwright.

**Spec:** ../../PROJECT_BRIEF.md

## Constraints
- Only modify the new repository. No public deploy or publishing.
- Keep core portfolio apps independent of simulation.
- Support pointer, keyboard and narrow viewports without inaccessible controls.

## Tasks and acceptance
1. BG-001 Foundation: scaffold, strict typecheck, lint, unit/browser test commands and CI; install lockfile. Build must pass.
2. BG-002 Window model: src/core/windows/windowReducer.ts exports windowReducer(state, action), initialState and AppId. tests/windows/windowReducer.test.ts must fail before implementation, then prove singleton open, active stacking, minimize fallback, restore, close, maximize, and bounded movement/resize.
3. BG-003 Shell: src/core/desktop/Desktop.tsx and src/core/windows/Window.tsx consume reducer actions. tests/desktop.test.tsx prove Start launch, Escape dismissal, minimize/restore and close. Browser tests prove pointer drag, keyboard movement, stacking and mobile fit.
4. BG-004 Delivery: typed content, original icon treatment, accessible retro styles, README, architecture, backlog, test evidence, and Amplify build configuration. Verify npm run check and npm run test:e2e. Commit local sprint branch.

## Review focus
- Reopening a minimized app must restore one instance.
- Closing/minimizing active windows must focus a visible remaining window.
- Viewport shrink and dragging must keep the title bar reachable.
- Start and window controls must work with keyboard and touch.
- ByteWire preview must not imply the game is implemented or activate effects.
